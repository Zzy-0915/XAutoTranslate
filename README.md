# XAutoTranslate v6 · 官方优先 / Google GTX 补位

面向 X 12.33（31）、iOS 17.2 及以上的 arm64 注入 dylib。使用 Apple iPhoneOS SDK 编译、ad-hoc 签名。先移除旧版 XAutoTranslate，避免同时加载多个版本；再通过 JailFools 注入本次 dylib，彻底退出 X 后重启。

## 双通道

可见推文、评论和引用内容优先使用 X 原生手动翻译事件路径，由插件自动触发，不需要逐一开启语言开关。中文跳过。官方返回失败或等待 8 秒仍无完整译文时，该内容自动转 Google GTX。未完成的官方网络任务没有已核对的安全取消接口，切换后可能仍会完成；插件不再为该内容提交第二条官方请求，统一缓存采用先成功结果，避免后到结果覆盖。

官方失败会暂停官方通道 5 分钟；暂停期间新内容直接使用 Google。到期后只允许一条探测请求，成功恢复官方优先，失败延长到 10 分钟、最多 15 分钟。已在途的其他官方请求成功不会提前取消暂停。原生自动翻译触发关闭，原生翻译事件只放行路由器本次主动提交的事件，避免界面自身重复触发。原生失败/重试提示隐藏，由统一正文模型显示结果。

若 X 的当前翻译目标语言能读取且不是中文，或原生接口缺失/不可用，会使用 Google 取得中文。官方路径遵循 X 自身的目标语言设置，请将 X 的显示语言设为中文。本地统一显示“语种 已翻译”，正文仍使用 X 的原生文本模型、高度测量及折叠/展开，不添加遮挡正文的译文浮层。原始推文模型保留原文。具体设备上的加载、官方状态提取和原生重排仍需通过实机日志确认。

Google 通过 HTTPS translate.googleapis.com/translate_a/single（client=gtx、sl=auto、tl=zh-CN）翻译。仅在补位时将原文发送给 Google，不发送 X 登录令牌、Cookie 或账号信息。GTX 仍可能返回 HTTP 429、存在网络限制或不支持某些语言；它没有免限流或永久可用的承诺。Google 请求最多并发两条，每秒启动至多一条，429/503 全局退避并遵守 Retry-After，其他错误有限重试。两个通道均不可用时保留原文，不显示虚假的成功状态。

## 统一内存缓存

任一通道成功后，完整译文在本次进程内保留。键包含推文 ID、原文及目标语言；相同内容来回滑动不再请求任一翻译通道，内容编辑后使用新键。同一条内容的在途请求合并，Google 相同分段还可复用。退出进程后缓存清空。原生渲染模型可在内存压力时清理，成功译文仍保留；长期使用内存占用随成功翻译文本增长。缓存命中无网络等待，不承诺严格 0ms 渲染。

## 临时日志

点击屏幕“日志”按钮，面板包含实时日志与导出日志。记录启动、挂钩、官方调度/成功/失败代码、官方暂停时间、Google 补位原因、请求状态、缓存、队列、退避等。不记录推文正文、完整请求 URL、响应正文或账号令牌。XAD_DIAGNOSTICS=0 编译移除诊断 UI 和日志写入。

## 构建与验证

bash scripts/build-ios.sh，产物位于 output/。GitHub Actions 用模拟服务器和模拟原生状态验证 Unicode、缓存、重复合并、并发、Google 429 退避、官方成功、自动补位、官方暂停/恢复探测、官方超时及双通道共用缓存，再构建带日志和无日志版本，并检查签名和 Mach-O 结构。测试不访问真实翻译网络；原生对象/状态测试使用模拟类，不代表手机已实测。build-info.txt 记录源码提交、工具链和文件 SHA-256。
